        atributo 'action' recebe a URL do destino dos dados inseridos naquele <form>;
        atributo 'method' é a forma de envio dos dados (metodo 'get' e 'post');
        tag <input>: tudo que eu coloco no atributo 'name' ajuda a localizar o valor de um input a um tipo de dado;
        atributo 'required' para tornar o campo obrigatório para preenchimento

        TAGS SEMANTICAS TANTO PARA SEO (MECANISMOS DE BUSCAS) QUANTO PARA O LEITOR DE TELE (ACESSIBILIDADE):
            <fieldset>: conjunto de assuntos que tem relação entre si

            <legend>: título da fieldset
